# hangul-audio

«Hangul en 14 días» 워크북과 «300 tarjetas de vocabulario coreano» 단어 카드의 발음 듣기 페이지입니다.
주소: https://haepoo.github.io/hangul-audio/

## 음성 파일
- `audio/` 폴더의 파일은 모두 음성합성(TTS)으로 만든 것입니다: Supertonic 3 (Supertone Inc., 모델 라이선스 OpenRAIL-M).
- 한 글자 음절은 두 번씩 읽고, 모든 항목 뒤에 따라 말할 수 있는 쉼이 들어 있습니다.

## 특정 트랙을 바꾸고 싶을 때
1. 이 저장소에서 `audio` 폴더를 엽니다.
2. **Add file → Upload files** 로 같은 이름의 파일(예: `wb-l01.m4a`)을 올리면 덮어씌워집니다.
3. **Commit changes** 를 누르면 1~2분 뒤 페이지에 반영됩니다.
