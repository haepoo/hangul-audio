# hangul-audio

«Hangul en 14 días» 워크북과 «300 tarjetas de vocabulario coreano» 단어 카드의 원어민 음성 재생 페이지입니다.
주소: https://haepoo.github.io/hangul-audio/

## 녹음 파일 올리는 법
1. 이 저장소에서 `audio` 폴더를 엽니다.
2. **Add file → Upload files** 를 누르고 녹음 파일을 끌어다 놓습니다.
3. 아래 **Commit changes** 를 누르면 1~2분 뒤 페이지에 반영됩니다.

- 파일 이름은 녹음 대본의 트랙 이름과 똑같이: 예) `wb-l01.m4a`, `tc-05.mp3`
- m4a, mp3 모두 됩니다. 파일이 없는 트랙은 "Este audio estará disponible muy pronto"(곧 제공)로 표시됩니다.

## 트랙 수
- 워크북 83개 (`wb-…`), 단어 카드 30개 (`tc-…`)
